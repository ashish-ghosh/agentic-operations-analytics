# Six-month transition roadmap

**Outcome sought:** move toward Data Analyst / BI Analyst / Business Analyst roles while building commercially testable analytics add-ons for property operations.

This is a plan, not a guarantee of employment or income. Progress should be evaluated by portfolio evidence, interview readiness, applications and customer validation.

## Monthly milestones

### Month 1 — Foundation and baseline
- Complete SQL diagnostic: joins, CTEs, window functions, aggregations and date logic.
- Refresh Excel: pivots, Power Query, lookups and clean data models.
- Build and publish one collection-recovery analysis using synthetic data.
- Set up the job tracker and baseline resume.

### Month 2 — Python and business analytics
- Use pandas for cleaning, validation, grouping and repeatable reports.
- Add complaint/SLA analysis and a short business case.
- Practise statistics: distributions, confidence, correlation, sampling and experiment basics.
- Publish one well-documented notebook or reproducible analysis per week.

### Month 3 — BI and analytics engineering
- Build a Power BI dashboard with a star schema, measures, DAX and documented metric definitions.
- Build SQL transformations and tests; study dbt Core after the Python toolkit is stable.
- Add DuckDB SQL examples over CSV/Parquet.
- Prepare a five-minute project walkthrough.

### Month 4 — Agentic analytics
- Understand tool calling, structured outputs, guardrails, traceability and human approval.
- Demonstrate the read-only MCP server with synthetic data.
- Run the optional job-description agent only with a locally configured API key.
- Add tests and architecture notes; do not market the demo as autonomous production software.

### Month 5 — Job-market execution
- Prioritise Data Analyst, BI Analyst, Operations Analyst, MIS/BI Analyst and Business Analyst roles.
- Target roles requiring SQL, Excel, Python and Power BI first; treat agentic AI as a differentiator.
- Apply to a measured shortlist each week, tailored to actual requirements.
- Practise SQL, Python, dashboard reasoning and business-case interviews.

### Month 6 — Interview conversion and product validation
- Refine portfolio based on interviewer feedback.
- Deliver two mock case-study presentations.
- Seek feedback from property managers/accounting professionals on the reconciliation and collections tools.
- Validate one paid pilot before spending on hosting, API usage or marketing.
- Review role conversion rates, interview stages and salary data before changing the job strategy.

## Weekly operating cadence

| Habit | Weekly target |
|---|---:|
| SQL / Python practice | 5 sessions |
| Portfolio engineering | 4 focused sessions |
| BI dashboard work | 2 sessions |
| Tailored job applications | 5 quality applications |
| LinkedIn drafts / learning notes | 2 drafts or 1 reviewed post |
| Interview practice | 2 sessions |
| Weekly review | 1 session |

## Daily routine (75 minutes)

1. 25 minutes: SQL or Python practice.
2. 25 minutes: improve or document a portfolio feature.
3. 15 minutes: review a relevant vacancy, tailor evidence or follow up.
4. 10 minutes: write a learning note or LinkedIn draft.

Adjust the routine for real work/family obligations; consistency is more valuable than unrealistic hours.

## Scorecard

Track weekly:
- SQL practice score and topics completed.
- Python exercises completed.
- Portfolio issues closed, tests passing and releases tagged.
- Applications submitted, recruiter responses, interviews and rejections.
- LinkedIn drafts/posts and profile visits where available.
- Customer discovery calls, pilot interest and willingness to pay.

Do not count GitHub stars, generated code volume or AI-agent buzzwords as proof of job readiness.
