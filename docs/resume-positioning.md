# Resume and portfolio positioning

## Recommended headline

**Business & Data Analyst | MSc Business Analytics | Python • SQL • Power BI • Tableau | Operations Intelligence**

## Professional summary draft

Business analytics postgraduate with a computer-science foundation and practical experience in facility operations, maintenance recovery, vendor coordination and complaint/SLA workflows. Building a portfolio of Python and SQL analytics projects that translate operational and financial data into clear KPIs, quality checks, reconciliation suggestions and management dashboards. Interested in Data Analyst, Business Intelligence Analyst and Operations Analyst roles.

| Skill | Evidence required |
|---|---|
| SQL | At least 20 original query examples using joins, CTEs, window functions and date logic |
| Python / pandas | Reproducible cleaning, validation and analysis with tests |
| Power BI | A documented data model, DAX measures, Power Query steps and screenshots |

| Analytics | Business question, data dictionary, assumptions, limitations and recommendations |
| Agentic AI | MCP tools with explicit permissions, traceability, failure handling and tests |
