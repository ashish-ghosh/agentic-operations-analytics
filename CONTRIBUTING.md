# Contributing

1. Create an issue describing the business problem or proposed change.
2. Use synthetic data in examples and tests.
3. Add or update tests for calculations and edge cases.
4. Run `ruff check .` and `pytest` locally.
5. Document assumptions, limitations and privacy implications.
6. Submit a pull request with a concise business-oriented explanation.

Never include credentials, real resident data, bank statements or employer-confidential files.
